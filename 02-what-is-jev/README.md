# Lesson 02 — What Is Jev? TypeSafe & RLCD

This lesson has no code. It covers who built Jev, how TypeSafe trains it with RLCD (Reinforcement Learning for Calibrated Decisions), and what TypeSafe has and hasn't published about the model.
